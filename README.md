# Challenge 6 – Multi-Source Learning Ingestion (MERN + OpenAI Whisper)

This is a **complete, ready-to-run MERN project** that ingests:

- PDFs
- Text documents & transcripts
- Audio files
- Video files

…and generates **structured learning artifacts**:

- Summaries
- Flashcards (JSON + CSV)
- Concept graphs
- Topic hierarchy & topic index

It uses:

- MongoDB
- Express + Node.js
- React + Vite
- OpenAI Whisper (`whisper-1`) for audio/video transcription

See backend/ and frontend/ READMEs and code comments for details.
